## 1. LUCID คืออะไร

**LUCID** คือแพลตฟอร์มกลางของร้าน **JE BAR** ที่รวมงาน 3 ด้านไว้ในแอปเดียว ใช้ได้ทั้งบนมือถือและคอมพิวเตอร์ (เปิดผ่านเว็บเบราว์เซอร์):

| ส่วน | ใครใช้ | ทำอะไรได้ |
|------|--------|-----------|
| 🧑‍🍳 **ฝั่งพนักงาน** | พนักงานหน้าร้าน / ครัว | ลงเวลาเข้า-ออก, ดูรายได้, ขอลา, แชตกับแอดมิน, ทำงานร้าน (บิล/ผลิต/สต๊อก) |
| 👔 **ฝั่งเจ้าของร้าน / แอดมิน** | เจ้าของร้าน / ผู้จัดการ | จัดการพนักงาน, ดูการลงเวลา, คำนวณเงินเดือน, สั่งงาน, ตั้งกฎ/วันหยุด |
| 🧁 **แคตตาล็อกสาธารณะ** | ลูกค้า (ไม่ต้องล็อกอิน) | ดูขนมในตู้วันนี้และคัดลอกรายการสั่งซื้อไปส่งใน LINE / Facebook |

LUCID ยังเชื่อมต่อกับระบบ **LUCID Operate** (ระบบ POS / เมนู / วัตถุดิบของร้าน) เพื่อดึงรายการเมนู
วัตถุดิบ และราคามาใช้ตอนพนักงานทำงานร้าน และส่งข้อมูลสต๊อก/การผลิตกลับไปให้ Operate

> **หมายเหตุความปลอดภัย:** แอปฝั่งพนักงานกับฝั่งแอดมินแยกออกจากกันโดยสิ้นเชิง พนักงานจะไม่เห็นหน้าจอของแอดมิน

## 2. เริ่มต้นใช้งาน

เปิดแอปครั้งแรกจะเจอ **หน้าเลือกบทบาท** พร้อมโลโก้ JE BAR และคำว่า *"STAFF & STORE PLATFORM"*
มีปุ่มให้เลือก 2 ปุ่ม:

- **เข้าสู่ระบบพนักงาน** → สำหรับพนักงาน (ล็อกอินด้วย PIN 4 หลัก)
- **เข้าสู่ระบบเจ้าของร้าน / แอดมิน** → สำหรับเจ้าของร้าน/ผู้จัดการ (ล็อกอินด้วยอีเมล + รหัสผ่าน)

> พนักงานที่ล็อกอินแล้วสามารถเข้าเมนู "ระบบร้าน / OPS" ได้จากในแอปพนักงานเลย ไม่ต้องล็อกอินซ้ำ

## 3. คู่มือสำหรับพนักงาน

### 3.1 เข้าสู่ระบบด้วย PIN

พนักงานเข้าระบบง่ายมาก ไม่ต้องใช้อีเมลหรือรหัสผ่าน — ใช้แค่ **PIN 4 หลัก**

1. กด **เข้าสู่ระบบพนักงาน**
2. หน้าจอ **"เลือกบัญชีของคุณ"** จะแสดงรายชื่อพนักงานทั้งหมด แต่ละคนมีรูป/ชื่อเล่น
   แตะที่ชื่อของตัวเอง
3. กรอก **PIN 4 หลัก** ผ่านแป้นตัวเลขบนหน้าจอ (จุด 4 จุดจะค่อยๆ เต็มเมื่อพิมพ์)
4. เมื่อครบ 4 หลัก ระบบ **ตรวจสอบและเข้าให้อัตโนมัติ** ไม่ต้องกดยืนยัน
   - พิมพ์ผิด → กด `⌫` เพื่อลบ
   - ถ้า PIN ไม่ถูกต้อง จะขึ้น *"PIN ไม่ถูกต้อง"* ให้ลองใหม่
   - อยากเปลี่ยนคน → กด **เปลี่ยนบัญชี**

> **ลืม PIN หรือใส่ผิดจนถูกล็อก?** แจ้งแอดมิน แอดมินสามารถ **ปลดล็อก** หรือ **ตั้ง PIN ใหม่** ให้ได้ทันที (ดูหัวข้อ 4.3)

---

### 3.2 หน้าหลัก

หลังเข้าสู่ระบบ จะเจอ **หน้าหลัก** ซึ่งเป็นศูนย์รวมทุกอย่าง:

- **คำทักทาย** — "สวัสดี, {ชื่อเล่น}" พร้อมกะและวันที่ (ระบบเดากะให้ตามเวลา: เช้า/บ่าย/เย็น)
- **สรุปเดือนนี้** — 4 ตัวเลข: `มาแล้ว` (วัน), `มาสาย` (ครั้ง), `ลา` (วัน), `OT` (ชม.)
- **สิทธิ์ลาคงเหลือ** — แสดงวันลาที่เหลือของปี: `ลาพักร้อน`, `ลาป่วย`, `ลากิจ` (แถบจะเป็นสีแดงเมื่อสิทธิ์หมด)
- **แถบสาขา/สถานะวันนี้** — บอกสาขาและสถานะ (มาทำงาน / มาสาย / ลา / ขาดงาน) พร้อมปุ่ม ⚙ ดู **"ระเบียบร้าน"**
- **ข้อความจากแอดมิน** — ถ้ามีข้อความใหม่จะขึ้นกล่องให้แตะดู
- **งานร้านวันนี้** — ปุ่มลัด 6 งาน (ถ่ายบิล, ใบสั่งซื้อ, ผลิตขนม, เช็กของ, ของใช้, สต๊อกเค้ก) — ดูรายละเอียดในหัวข้อ 3.8
- **งานที่ต้องทำ** — งานที่แอดมินมอบหมายและยังไม่เสร็จ (แจ้งเตือน "วันนี้!" ถ้าครบกำหนด)
- **การ์ดลงเวลา (สีเข้มด้านล่าง)** — นาฬิกาเรียลไทม์ + ปุ่มลงเวลาใหญ่

---

### 3.3 ลงเวลาเข้า–ออกงาน

นี่คือฟังก์ชันที่ใช้บ่อยที่สุด อยู่ในการ์ดสีเข้มด้านล่างของหน้าหลัก
ปุ่มจะเปลี่ยนข้อความเองตามสถานะ:

- ยังไม่เข้างาน → **ลงเวลาเข้างาน**
- เข้างานแล้ว ยังไม่ออก → **ลงเวลาออกงาน**

เมื่อกดปุ่ม ระบบจะพาทำทีละขั้น (ข้ามขั้นที่ไม่จำเป็น):

**ขั้นที่ 1 — ตรวจสอบตำแหน่ง** 🔍
ระบบเช็กว่าคุณอยู่ในพื้นที่ร้านหรือไม่ (ถ้าเปิด Geofence)
- อยู่นอกพื้นที่ → ขึ้น *"📍 อยู่นอกพื้นที่"* พร้อมบอกระยะห่าง — จะลงเวลาไม่ได้ ต้องเข้ามาใกล้ร้านก่อน
- ถ้าร้านไม่ได้เปิด Geofence จะข้ามขั้นนี้

**ขั้นที่ 2 — ถ่ายเซลฟี่** 📸 (เฉพาะตอนเข้างาน ถ้าร้านตั้งให้บังคับ)
- กด **ถ่ายภาพ** เพื่อยืนยันตัวตน
- ถ้ากล้องใช้ไม่ได้ ระบบจะสร้างภาพยืนยันแทนให้อัตโนมัติ

**ขั้นที่ 3 — เช็กลิสต์ปิดงาน** ✅ (เฉพาะตอนออกงาน ถ้ามีรายการที่ต้องทำก่อนปิดร้าน)
- ติ๊กให้ครบทุกข้อ ปุ่ม **ต่อไป** จะกดได้ก็ต่อเมื่อติ๊กครบ

**ขั้นที่ 4 — ยืนยัน**
- ตรวจดูรูปเซลฟี่ เวลา และระยะห่าง แล้วกด **ยืนยัน**

**ขั้นที่ 5 — สำเร็จ** ✅
- ขึ้น *"บันทึกสำเร็จ!"* พร้อมเวลาที่ลง มีเสียงยืนยัน

> **สาย/OT คิดให้อัตโนมัติ:** ถ้าเข้าหลังเวลาเริ่มงาน + เวลาผ่อนผัน จะถูกบันทึกเป็น "มาสาย"
> ถ้าออกหลังเวลาเลิกงาน + ระยะผ่อนผัน OT ระบบจะเริ่มนับ OT ให้

### 3.4 ประวัติ

แท็บ **ประวัติ** เก็บบันทึกส่วนตัวของคุณ แบ่งเป็น 3 แท็บย่อย:

**การลงเวลา** — รายการรายวัน: วันที่ เวลาเข้า–ออก และสถานะ (มาทำงาน / มาสาย / ลา / ขาด)

**การลา** — ดูคำขอลาเดิม และขอลาใหม่
1. กด **+ ขอลาใหม่**
2. เลือก **ประเภทการลา**: `ลาป่วย` / `ลากิจ` / `ลาพักร้อน`
3. เลือก **วันที่เริ่ม** และ **วันที่สิ้นสุด**
4. กรอก **เหตุผล**
5. กด **ส่งคำขอ**

> ⚠️ **ลาด่วนวันนี้โดยไม่มีเหตุผลจะถูกหักเงิน** — ถ้าเลือกลาวันนี้และไม่กรอกเหตุผล ระบบจะเตือนจำนวนเงินที่จะถูกหักก่อน

สถานะคำขอ: `รอพิจารณา` → `อนุมัติ` / `ไม่อนุมัติ` (แอดมินเป็นผู้อนุมัติ)

**งานร้าน** — ดูบันทึกงานร้านที่คุณเคยส่ง (บิล / ผลิต / สต๊อก ฯลฯ) กรองตามประเภทได้

---

### 3.5 รายได้และสลิปเงินเดือน

แท็บ **รายได้** แสดงเงินที่คุณจะได้รับในรอบนี้

- **เลือกช่วง:** `วันนี้` / `สัปดาห์` / `เดือน`
  - พนักงานรายสัปดาห์เห็นเฉพาะ "สัปดาห์" / รายเดือนเห็นเฉพาะ "เดือน" / รายวันสลับได้
- **ค่าจ้างต่อวัน** — อัตราต่อวันและจำนวนวันทำงานในรอบ
- **เงินสุทธิ** — ยอดที่จะได้รับจริง พร้อมจำนวนวันทำงาน / วันลา / วันขาด
- **รายละเอียด** — แยกเป็นรายรับ (ค่าแรง, OT, คอมมิชชั่น, โบนัส) และรายการหัก (หักสาย, ค่าเสียหาย, เบิกล่วงหน้า, ประกันสังคม ฯลฯ)
- ถ้าแอดมินทำเครื่องหมายว่าจ่ายแล้ว จะเห็นแถบเขียว *"จ่ายเงินงวดนี้แล้ว"* พร้อมวันที่และยอด

**ดาวน์โหลดสลิป:** กด **⬇ ดาวน์โหลดสลิปเงินเดือน** จะได้ไฟล์รูปสลิป (PNG) มีโลโก้ JE BAR รายรับ-รายการหัก และยอดสุทธิ

### 3.6 ข้อความ

แท็บ **ข้อความ** คือแชตสองทางระหว่างคุณกับแอดมิน

- ข้อความของแอดมินอยู่ซ้าย ข้อความของคุณอยู่ขวา จัดกลุ่มตามวัน
- **งานที่มอบหมาย** จะมีป้าย "งานที่มอบหมาย" และแสดงกำหนดส่ง (เช่น "⏰ กำหนดวันนี้!")
  - ทำเสร็จแล้วกด **✓ ทำเสร็จแล้ว**
- พิมพ์ข้อความในช่องล่าง กด **ส่ง** (หรือกดปุ่มไมค์เพื่อพูดแทนพิมพ์)
- เปิดแท็บนี้แล้วข้อความจากแอดมินจะถูกทำเป็น "อ่านแล้ว" อัตโนมัติ

### 3.7 โปรไฟล์

แท็บ **โปรไฟล์** ดูและแก้ไขข้อมูลติดต่อของตัวเอง

- **ข้อมูลทั่วไป** (แก้ไขได้): เบอร์โทร, เลขบัตรประชาชน, รูปบัตร, ธนาคาร, เลขบัญชี, ผู้ติดต่อฉุกเฉิน
  กด **แก้ไข** เพื่อปรับ แล้วกด **บันทึก** (การเปลี่ยนแปลงจะแจ้งแอดมินอัตโนมัติ)
- **ข้อมูลการเงิน (แอดมินเท่านั้น)** (ดูอย่างเดียว): สาขา, วันหยุดประจำ, ประเภทค่าจ้าง, อัตราค่าจ้าง, เวลาทำงาน, เวลาผ่อนผันสาย
- กด **ออกจากระบบ** เพื่อล็อกเอาต์

### 3.8 LUCID OPS — งานร้าน 6 อย่าง

**LUCID OPS** คือศูนย์รวมงานหน้าร้านของพนักงาน เข้าได้จากปุ่มลัดในหน้าหลัก หรือกด **ดูทุกเมนูงาน ›**

แต่ละงานมีป้ายบอกสถานะ: `✓ {จำนวน}` ถ้าทำวันนี้แล้ว, `⚠️ ต้องติดตาม` ถ้ามีของใกล้หมด, `• ร่างค้าง` ถ้ามีร่างที่ยังไม่บันทึก

ทุกฟอร์มมีหัวข้อ **วันที่** และ **ผู้บันทึก** (เติมชื่อให้อัตโนมัติ) ช่องข้อความมีปุ่มไมค์พูดได้
และเมื่อบันทึกจะมีปุ่ม **บันทึกเข้า backend** และ **ล้างฟอร์ม** พร้อมประวัติรายการล่าสุด

> 💡 ช่องเลือกรายการ (เมนู/วัตถุดิบ) จะดึงจากระบบ Operate ถ้ายังไม่เชื่อมต่อ ให้พิมพ์ชื่อเองได้ และกด **🔄 ลองใหม่**

#### 1) ถ่ายบิลซื้อของ 🧾
บันทึกบิลค่าใช้จ่าย พร้อม AI ช่วยอ่านรายการ
1. กด **📷 ถ่ายรูป** หรือ **🖼️ อัลบัม** เพื่อใส่รูปบิล
2. (ถ้าเปิด AI) กด **🤖 AI อ่านบิล** ระบบจะอ่านรายการออกมาเป็นตารางให้ตรวจแก้ (ชื่อ/จำนวน/หน่วย/ราคา)
3. กรอก **ร้าน/ผู้ขาย**, **ยอดบิล**, เลือก **ประเภท** (วัตถุดิบ/ของใช้/อุปกรณ์/อื่นๆ), **หมายเหตุ**
4. กด **บันทึกเข้า backend**

> ถ้า AI ยังไม่พร้อม จะขึ้น *"AI ยังไม่พร้อม — แจ้งแอดมินเพื่อเปิดใช้งาน"* (แอดมินตั้งค่า Gemini Key ในหัวข้อ 4.8)

#### 2) บันทึกการผลิตขนม 🏭
1. เลือก **เมนูที่ผลิต** (ถ้าผลิตวันนี้แล้วจะโชว์ยอดรวม)
2. กรอก **จำนวน** + **หน่วย** (ชิ้น/ถาด/ก้อน/กก. ฯลฯ)
3. เลือก **รอบผลิต/batch** (เช้า/บ่าย/เย็น/รอบ 1/รอบ 2)
4. (ถ้ามี) เพิ่ม **ส่งไปสาขา** ระบุสาขา + จำนวน
5. ใส่รูปการผลิต (ไม่บังคับ) แล้วกดบันทึก

> ช่อง **เลขใบงาน** — ถ้าใส่เลขเดิม จะเป็นการเขียนทับรายการนั้น

#### 3) วัตถุดิบและสต๊อก 📦
เช็กวัตถุดิบคงเหลือ
1. เลือก **ชื่อวัตถุดิบ** (โชว์ยอดครั้งล่าสุดให้ดู)
2. กรอก **คงเหลือ** + **หน่วย**
3. เลือก **สถานะ**: ปกติ / ใกล้หมด / หมดแล้ว / ต้องสั่งเพิ่ม / มีปัญหา
4. บันทึก — ถ้าสถานะไม่ปกติ ระบบถามว่าจะ **+ เพิ่มในใบสั่งซื้อ** เลยไหม

#### 4) เช็คสต๊อกเค้ก 🍰
นับเค้กหน้าตู้แยกตามสาขา — ดูรายละเอียดในหัวข้อ 3.9

#### 5) นับสต๊อกของใช้ 🧻
นับของใช้สิ้นเปลือง (ทิชชู่ น้ำยา ฯลฯ)
1. เลือก **จุดที่นับ** (หน้าร้าน/ครัว/สต๊อกหลังร้าน/ล้างจาน)
2. เลือก **รายการของใช้**, กรอก **จำนวนคงเหลือ** + หน่วย
3. เลือก **สถานะ** แล้วบันทึก (ถ้าไม่ปกติ ถามเพิ่มใบสั่งซื้อเหมือนกัน)

#### 6) ใบสั่งซื้อก่อนไปซื้อ 🛒
เตรียมรายการที่ต้องซื้อ
1. ดู **⚡ แนะนำจากสต๊อกต้องติดตาม** ระบบดึงของใกล้หมดมาให้ — กด **+ เลือก** เพื่อเพิ่ม
2. หรือกด **+ เพิ่มรายการสั่งซื้อ**: เลือกหมวด → เลือกรายการ (ระบบเช็กสต๊อกให้)
   - ⚠️ ถ้าของยังเหลือเยอะ ระบบจะเตือนให้ไปตรวจของจริงก่อน (กันสั่งซ้ำ)
3. กรอก **จำนวน** + หน่วย, เลือก **ความด่วน** (วันนี้/พรุ่งนี้/ภายในสัปดาห์/ไม่ด่วน), หมายเหตุ
4. กด **+ เพิ่มรายการ** เพื่อใส่ลงลิสต์ แล้วบันทึก

### 3.9 สต๊อกเค้ก

หน้า **สต็อกขนม** เป็นตัวจัดการสต๊อกเค้ก/เบเกอรีแบบละเอียด แยกตามสาขา
**แก้ไขได้เฉพาะสาขาของตัวเอง** (สาขาอื่น + "รวมทุกสาขา" ดูได้อย่างเดียว)

**สิ่งที่ทำได้:**
- **ปรับจำนวน** เค้กแต่ละรายการด้วยปุ่ม −/+
- **↻ Operate** — ดึงจำนวน/ราคา/หมวดจากระบบ Operate
- **รับผลผลิต** — ถ้ามีการผลิตส่งมา จะขึ้นแถบ *"📦 ผลผลิตใหม่"* กด **✓ รับ** เพื่อเข้าสต๊อก
- **บันทึกของเสีย** — เข้า **รายละเอียด ›** ของแต่ละชิ้น ระบุจำนวนเสีย + สาเหตุ (หมดอายุ/เสียหาย/คุณภาพ) + ถ่ายรูป
- **ใส่รูป + ราคา** ของขนม (สำหรับแคตตาล็อก)
- **เปิด/ปิดขาย** แต่ละรายการ
- **ขอเพิ่ม / ขอลบ รายการ** — ส่งให้แอดมินอนุมัติก่อน
- **🔗 แคตตาล็อก** — สร้างลิงก์แชร์เมนูให้ลูกค้า (ดูหัวข้อ 5) กด **📋 คัดลอกลิงก์** แล้วส่งผ่าน LINE/Messenger
- **ส่งรายงาน** — เมื่อเช็กเสร็จ กด **ส่งรายงาน** ให้แอดมิน
- **ประวัติ** (30 วัน) และ **Export** เป็นรูปตาราง

> เมื่อเชื่อม Operate แล้ว จะมีโหมด **"เช็คสต๊อกเค้ก"** แบบเลือกหลายรายการพร้อมกัน ใส่จำนวน "พร้อมขาย/จอง/เสีย" แล้วบันทึกทีเดียว (มีเตือนถ้าเพิ่งบันทึกซ้ำภายใน 30 นาที)

## 4. คู่มือสำหรับเจ้าของร้าน / แอดมิน

### 4.1 เข้าสู่ระบบแอดมิน

1. จากหน้าแรก กด **เข้าสู่ระบบเจ้าของร้าน / แอดมิน**
2. กรอก **อีเมล** และ **รหัสผ่าน**
3. กด **เข้าสู่ระบบ**

เมนูแอดมินอยู่ในแถบด้านข้าง (กดปุ่ม ☰ มุมบนซ้ายเพื่อเปิด): ภาพรวม · พนักงาน · การลงเวลา · คำนวณเงิน · ข้อความ · งานร้านพนักงาน · กฎ/วันหยุด
ด้านล่างมีปุ่ม **เปิดระบบร้าน / OPS** (ไปยัง LUCID Operate) และ **ออกจากระบบ**

---

### 4.2 ภาพรวมวันนี้

หน้า **ภาพรวม** สรุปสถานการณ์ร้านวันนี้:

- **แจ้งเตือนด้านบน** — มีพนักงานตอบกลับกี่ราย, งานที่มอบหมายค้างอยู่กี่ราย
- **4 การ์ดสถิติ** — กำลังทำงาน / มาสายวันนี้ / ลาวันนี้ / ยอดเงินเดือนนี้
- **⚠️ สต๊อกต้องติดตาม** — รวมของใกล้หมดจากทุกงานร้าน กดไปดูใน OpsInbox ได้
- **สถานะวันนี้** — รายชื่อพนักงานทุกคนพร้อมสถานะ (ทำงาน/สาย/ลา)
- **คำขอลารอพิจารณา** — กด **อนุมัติ** / **ปฏิเสธ** ได้จากตรงนี้เลย
- **งานร้านที่พนักงานส่งเข้ามา** — จำนวนงานแต่ละประเภทวันนี้ กดเข้าดูใน OpsInbox

---

### 4.3 จัดการพนักงาน

หน้า **พนักงาน** ใช้เพิ่ม/แก้ไขพนักงานและตั้งค่ารายบุคคล

**เพิ่มพนักงานใหม่:**
1. กด **+ เพิ่มพนักงาน**
2. กรอกข้อมูล: ชื่อ-นามสกุล (บังคับ), ชื่อเล่น, ตำแหน่ง, แผนก, เบอร์, สาขา
3. ตั้ง **รอบจ่ายเงิน**: รายวัน / รายสัปดาห์ / รายเดือน + **อัตราค่าจ้าง (บาท/วัน)**
   - รายสัปดาห์: เลือกวันเริ่มรอบสัปดาห์ / รายเดือน: เลือกวันที่เริ่มรอบเดือน
4. เลือก **วันหยุดประจำ** ของพนักงาน (อาทิตย์–เสาร์)
5. ตั้ง **โควต้าวันลาต่อปี** (ลาพักร้อน / ลาป่วย)
6. ตั้ง **PIN 4 หลัก** ให้พนักงาน (จำเป็นตอนสร้างใหม่)
7. (ตัวเลือก) เช็กลิสต์ก่อนออกงาน, คอมมิชชั่น, สีประจำตัว, ข้อมูลธนาคาร/ผู้ติดต่อฉุกเฉิน
8. กด **บันทึก** แล้วคัดลอก **ลิงก์แอปพนักงาน** ส่งให้พนักงาน

**ในหน้ารายละเอียดพนักงาน ทำได้อีกหลายอย่าง:**
- **แก้ไข** ข้อมูล / **PIN** (ดู, ปลดล็อก, หรือตั้งใหม่) / **ส่งข้อความ** / **ลบพนักงาน**
- ดูสรุปเงิน (เลือกช่วง วันนี้/สัปดาห์/เดือน) และ **ตารางสรุปรายวัน**
- **โบนัส / รายการหัก** — กด **+ เพิ่ม** ระบุประเภท (โบนัส/หักเสียหาย/เบิกล่วงหน้า/หักอื่นๆ), จำนวน, วันที่, เหตุผล
- **คำขอลา** — อนุมัติ/ปฏิเสธ
- **ประวัติรายวัน** — กด **แก้วัน** เพื่อแก้สถานะ/เวลาของแต่ละวัน

### 4.4 การลงเวลา

หน้า **การลงเวลา** มี 2 แท็บ:

**รายวัน:**
- เลือกวันด้วยปุ่ม ← / → หรือปฏิทิน
- ดูสรุป: มาทำงาน / มาสาย / ลา / ขาด / OT รวม
- ตารางแสดงเวลาเข้า-ออก, ระยะห่าง, เซลฟี่, สถานะ
- คอลัมน์ **จัดการ** แก้ไขได้: อนุมัติ/ปฏิเสธใบลา, **แก้เวลาเข้า**, **ใส่เวลาออก**, **ล้างเวลาออก**, **ลบรายการ**
- ส่งออก **📥 CSV** ได้

**สรุปรายเดือน:**
- เลือกเดือน ดูยอดรวมทั้งร้าน + ตารางสรุปต่อพนักงาน (ทำงาน/สาย/ลา/ขาด/OT) และ Export CSV

---

### 4.5 คำนวณเงินเดือน

หน้า **คำนวณเงิน** รวมการคำนวณเงินของพนักงานทุกคน

1. เลือกช่วง: **วันนี้ / สัปดาห์ / เดือน** (กรองตามสาขาและประเภทค่าจ้างได้)
2. ดู **ยอดจ่ายรวม** และจำนวนคนที่จ่ายแล้ว
3. แต่ละคนแสดง **สุทธิที่ต้องจ่าย** พร้อมรายละเอียด (ค่าแรง, OT, คอม, โบนัส, หัก, ประกันสังคม)

**ปุ่มจัดการต่อคน:**
- **✓ ทำเครื่องหมายจ่ายแล้ว** / **↩ ยกเลิกจ่าย**
- **รายละเอียด** — ดูรายรับ/รายการหัก
- **ดูรายวัน** — ตารางรายวัน กด **แก้ไข** แต่ละวันได้
- **แก้ประกันสังคม** — ปรับต่อคน (ตามกฎ / ไม่หัก / คงที่ / เปอร์เซ็นต์)
- **เบิก / หักล่วงหน้า** — บันทึกการเบิกเงิน
- **ปรับยอดจริง** — พิมพ์ยอดสุทธิที่จ่ายจริง (ส่วนต่างเก็บเป็นรายการปรับ)
- **สลิป** — ดาวน์โหลดสลิป PNG
- **ส่งให้พนักงาน** — ส่งสรุปเงินเดือนเข้าแชตพนักงาน

ส่งออกทั้งหมดเป็น **Export CSV** ได้

---

### 4.6 ข้อความ & สั่งงาน

หน้า **ข้อความ** แชตกับพนักงานและมอบหมายงาน

- เลือกพนักงานจากรายการซ้าย (มีป้ายงานค้าง 📋 และจำนวนข้อความที่ยังไม่อ่าน)
- พิมพ์ข้อความ หรือสลับเป็น **📋 มอบงาน** แล้วกำหนดวันส่ง จากนั้นกด **ส่ง**
- สถานะข้อความ: ✓ (ส่งแล้ว) / ✓✓ อ่านแล้ว / ✓✓ ทำงานเสร็จ
- **📣 ส่งให้ทุกคน (Broadcast)** — ส่งข้อความ/งานถึงพนักงานทุกคนพร้อมกัน

---

### 4.7 กล่องงานร้านพนักงาน

หน้า **งานร้านพนักงาน (OpsInbox)** รวมทุกอย่างที่พนักงานส่งผ่าน OPS

- **การ์ดนับจำนวน** แต่ละประเภท (บิล/ผลิต/วัตถุดิบ/สต๊อกเค้ก/ของใช้/ใบสั่งซื้อ)
- **ตัวกรอง:** ค้นหา, ตามประเภท, ตามพนักงาน, ตามวันที่ (ทั้งหมด/วันนี้/7 วัน/กำหนดเอง), ซ่อนที่ดูแล้ว
- **สรุปวันนี้:** การผลิต, บิล, สต๊อกเค้กแยกสาขา, และของที่ต้องติดตาม
- แต่ละรายการดูรายละเอียด (ค่าที่กรอก + รูป) ทำเครื่องหมาย **✓ ดูแล้ว** และกด **↩ ตอบ** เพื่อตอบกลับ/สั่งงานต่อ
- ปุ่ม **📋 สรุปวันนี้** คัดลอกสรุปไปวางใน LINE, และ **📥 CSV** ส่งออกได้
- ใบสั่งซื้อจะแสดงเป็นตารางพร้อมปุ่ม **📋 คัดลอก** เป็นข้อความ

---

### 4.8 ตั้งค่ากฎ / วันหยุด

หน้า **กฎ/วันหยุด** ตั้งค่าการทำงานของทั้งระบบ

**วันหยุดพิเศษ (Global):** เพิ่มวันหยุดตามวันที่ + ตั้งว่า **หยุดได้เงิน** หรือ **หยุดไม่ได้เงิน**

**การตั้งค่า Global (ทุกสาขา):**
- เปิด/ปิด **Geofence** (บังคับอยู่ในพื้นที่)
- เปิด/ปิด **บังคับถ่ายเซลฟี่ตอนเช็คอิน**
- ตั้ง **ระเบียบร้าน Global**

**กฎรายสาขา** (เลือกสาขา แล้วตั้งค่า):
- วันหยุดพิเศษของสาขา
- **เวลาทำงาน** (เข้า/เลิก/ผ่อนผัน)
- **กฎมาสาย** — แบบขั้นบันได หรือ ต่อนาที
- **OT** — เริ่มนับหลังเลิกงานกี่นาที และคิดเป็น x เท่า หรือ บาท/ชม.
- **ประกันสังคม** — เปอร์เซ็นต์ (มีเพดาน) หรือ ยอดคงที่
- **การลา** — ลาด่วนไม่มีเหตุผล หักกี่แรง
- **ระเบียบร้าน** ที่แสดงในแอปพนักงาน

**🔗 เชื่อมต่อระบบ OPS (LUCID Operate):**
- ใส่ **Supabase URL** + **Anon Key** (หรือกด **✨ กรอกอัตโนมัติ**)
- กด **บันทึกการเชื่อมต่อ** แล้ว **🔍 ทดสอบการเชื่อมต่อ** (สำเร็จจะโชว์จำนวนเมนู/วัตถุดิบ/วัสดุ)

**🤖 AI อ่านบิล (Google Gemini):**
- ใส่ **Gemini API Key** แล้วกด **บันทึก** — ตั้งครั้งเดียว พนักงานทุกคนใช้ AI อ่านบิลได้

**เพิ่ม/แก้ไขสาขา:** ตั้งชื่อสาขา, รัศมี Geofence (เมตร), พิกัด (วางลิงก์ Google Maps ได้ หรือกด 📍 ใช้ตำแหน่งปัจจุบัน), และ **LINE Notify Token** (สำหรับแจ้งเตือนใบลา)

## 5. แคตตาล็อกสาธารณะ

หน้าแคตตาล็อกเป็นลิงก์สาธารณะ **"ขนมในตู้วันนี้"** ให้ลูกค้าเปิดดูโดยไม่ต้องล็อกอิน
(สร้างลิงก์จากหน้าสต๊อกเค้ก → **🔗 แคตตาล็อก**)

**ลูกค้าใช้งานอย่างไร:**
1. เปิดลิงก์ เห็นขนมที่พร้อมขายวันนี้พร้อมราคาและจำนวนคงเหลือ
2. กด −/+ เลือกจำนวนที่ต้องการ (เลือกได้ไม่เกินที่มีในสต๊อก)
3. กด **คัดลอกข้อความสั่งซื้อ**
4. นำไปวางส่งใน **LINE OA** หรือ **Facebook Inbox** ของร้าน
5. รอร้านตรวจสอบและยืนยัน

> แสดงเฉพาะขนมที่ "เปิดขาย" และยังมีของ ของที่เหลือ ≤ 3 ชิ้นจะขึ้น ⚡ สีแดง

## 6. กฎการคำนวณเงินเดือน

ระบบคำนวณเงินให้อัตโนมัติ โดยกฎไล่ระดับ **ร้าน (Global) → สาขา → รายบุคคล** (ค่าที่ตั้งเฉพาะคนจะทับค่าของสาขา)

**สูตรสุทธิ:**
```
รายรับ  = ค่าแรง + OT + คอมมิชชั่น + โบนัส
รายการหัก = หักสาย + ค่าเสียหาย + เบิกล่วงหน้า + หักอื่นๆ + ประกันสังคม
เงินสุทธิ = รายรับ − รายการหัก
```

| หัวข้อ | คำอธิบาย |
|--------|----------|
| **เวลาทำงาน & ผ่อนผัน** | ค่าเริ่มต้น 09:00–18:00 (8 ชม.) ผ่อนผัน 5 นาที เข้าเกินเวลา+ผ่อนผัน = "มาสาย" |
| **หักมาสาย** | *ต่อนาที* (หักบาทต่อนาที) หรือ *ขั้นบันได* (สายเกินเกณฑ์ใหญ่หักทันที, สายย่อยสะสมครบจำนวนครั้งก็หัก) |
| **OT** | เริ่มนับหลังเลิกงาน + ระยะผ่อนผัน (ค่าเริ่มต้น 30 นาที) คิดเป็น x เท่าของค่าแรง หรือ บาท/ชม.คงที่ |
| **ประกันสังคม** | เปอร์เซ็นต์ของค่าจ้าง (มีเพดาน) หรือยอดคงที่ ปรับ/ยกเว้นรายคนได้ |
| **รอบจ่าย** | รายวัน / รายสัปดาห์ (เลือกวันเริ่มรอบ) / รายเดือน (เลือกวันที่เริ่มรอบ) คิดตามรอบของแต่ละคน |
| **วันหยุดประจำ** | วันหยุดประจำสัปดาห์ลดจำนวนวันทำงานตามตารางในรอบ |
| **การลา** | ลาป่วย/ลากิจ/ลาพักร้อน — ลาแบบได้เงิน (นับเป็นวันจ่าย) หรือไม่ได้เงิน มีโควต้าต่อปี |
| **ลาด่วนไม่มีเหตุผล** | ลาวันนี้โดยไม่มีเหตุผล ถูกหักตามที่ตั้งไว้ (ค่าเริ่มต้น 2 แรง/วัน) เตือนก่อนส่ง |
| **วันหยุดพิเศษ** | กำหนดตามวันที่ ตั้งได้ทั้ง "ได้เงิน"/"ไม่ได้เงิน" วันได้เงินที่ตรงวันทำงานจะนับเป็นวันจ่ายเพิ่ม |
| **โบนัส/หัก** | โบนัส (+), หักเสียหาย (−), เบิกล่วงหน้า (−), หักอื่นๆ (−) |
| **คอมมิชชั่น** | เปอร์เซ็นต์ยอดขาย หรือ บาท/ชิ้น |

> วันที่ทั้งหมดแสดงเป็นภาษาไทยและปี พ.ศ. เช่น "พฤ. 17 ก.ค. 2569"

## 7. คำถามพบบ่อย / แก้ปัญหา

**Q: พนักงานลืม PIN / ใส่ผิดจนถูกล็อก?**
A: แจ้งแอดมิน → หน้า **พนักงาน** → เลือกคนนั้น → **PIN** → กด **ปลดล็อก PIN ทันที** หรือ **ตั้ง PIN ใหม่**

**Q: ลงเวลาเข้าไม่ได้ ขึ้น "อยู่นอกพื้นที่"?**
A: ต้องอยู่ในรัศมีร้านตามที่ตั้ง Geofence ไว้ ให้เข้ามาใกล้ร้านก่อน หรือแอดมินปรับรัศมี/พิกัดสาขาในหน้าตั้งค่า

**Q: กล้องถ่ายเซลฟี่ไม่ขึ้น?**
A: อนุญาตสิทธิ์กล้องในเบราว์เซอร์ ถ้ายังไม่ได้ ระบบจะสร้างภาพยืนยันแทนให้อัตโนมัติ

**Q: AI อ่านบิลไม่ได้ ขึ้น "AI ยังไม่พร้อม"?**
A: แอดมินต้องใส่ **Gemini API Key** ที่หน้า **กฎ/วันหยุด → AI อ่านบิล** ก่อน แล้วพนักงานล็อกอินใหม่

**Q: ช่องเลือกเมนู/วัตถุดิบว่างเปล่า?**
A: แอดมินต้องเชื่อมต่อ **LUCID Operate** ในหน้าตั้งค่า และในฝั่ง Operate ต้องกด "ซิงก์ขึ้น" ให้มีข้อมูลก่อน — ระหว่างนี้พิมพ์ชื่อเองได้

**Q: เพิ่มของลงใบสั่งซื้อไม่ได้ ขึ้น "สต๊อกยังเหลือ"?**
A: เป็นระบบกันสั่งซ้ำ — ของยังเหลือตามที่บันทึกล่าสุด ให้ไปตรวจของจริงก่อน

**Q: พนักงานเห็นหน้าแอดมินได้ไหม?**
A: ไม่ได้ — สองฝั่งแยกกันสนิท พนักงานเข้าได้แค่แอปพนักงานและ OPS

**Q: เลขเวอร์ชันอยู่ตรงไหน?**
A: มุมขวาล่างของหน้าจอมีป้ายบอกเวอร์ชัน (เช่น `Build 2026.07.02-special-holiday-pay`) — ใช้อ้างอิงเวลาแจ้งปัญหา

## 8. อภิธานศัพท์

| คำ | ความหมาย |
|----|----------|
| **LUCID** | ชื่อแพลตฟอร์มกลางของร้าน JE BAR |
| **LUCID Operate** | ระบบ POS / เมนู / วัตถุดิบ ที่เชื่อมกับ LUCID |
| **OPS / งานร้าน** | งานหน้าร้านที่พนักงานบันทึก (บิล/ผลิต/สต๊อก/ใบสั่งซื้อ) |
| **PIN** | รหัส 4 หลักสำหรับพนักงานเข้าระบบ |
| **Geofence** | การจำกัดพื้นที่ลงเวลา (ต้องอยู่ในรัศมีร้าน) |
| **OT** | ค่าล่วงเวลา (Overtime) |
| **แรง** | หน่วยหักเงินเทียบเป็นชั่วโมง/วันค่าแรง |
| **รอบจ่าย** | ช่วงเวลาคำนวณเงิน (รายวัน/สัปดาห์/เดือน) |
| **OpsInbox** | กล่องรวมงานร้านที่พนักงานส่งเข้ามา (ฝั่งแอดมิน) |
| **Broadcast** | ส่งข้อความ/งานถึงพนักงานทุกคนพร้อมกัน |
| **แคตตาล็อก** | ลิงก์สาธารณะให้ลูกค้าดูขนมและสั่งซื้อ |
